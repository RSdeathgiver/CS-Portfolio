# IT 230 – Software Development Portfolio

## Project Overview

Throughout this course, I worked on several C# applications using Visual Studio, including console applications and a Windows Presentation Foundation (WPF) application. The main goal was to develop and debug programs while learning how to work with existing code and implement requirements. One of the main projects involved creating a student registration application. The goal was to provide users with a way to interact with the program and work with student and course information.

## What I Did Well

I think one thing I did particularly well was becoming more comfortable with debugging existing code. Throughout the course, I worked on identifying errors involving methods, classes, constructors, and conditional statements. Instead of trying to fix everything at once, I learned to work through errors individually and test the program after making changes. I also became more comfortable navigating Visual Studio and understanding how different parts of a program work together.

## Console vs. WPF Application Design

One of the biggest differences between the console and WPF applications was how users interacted with them. The console application relied on text-based input and output, while the WPF application used a graphical user interface with controls that users could interact with. The console application was simpler in appearance and focused more on the functionality of the code. The WPF application required more attention to the layout and placement of controls to make it easier for users to navigate. Both approaches were useful, but I think WPF provides a more user-friendly experience because users can interact with visual elements instead of relying entirely on text commands.

## Debugging and Coding Strategies

My approach to debugging was to first review the existing code and identify what the program was supposed to accomplish. I then used Visual Studio's error messages to help locate problems and worked through them one at a time. After making corrections, I would run the program to see whether the changes worked as expected. I also learned the importance of checking method parameters, return types, and access modifiers when working with classes and objects. These are strategies I plan to continue using in future programming projects because they make it easier to understand problems instead of just guessing at solutions.

## Overcoming Challenges

One of the biggest challenges I faced during this course was working with classes and objects. This has been something that has slowed me down in other programming languages as well. Understanding how constructors, methods, and different classes interact took some extra time. Another challenge was working with the WPF interface because it required me to think about both the code and how the application looked to the user. I worked through these challenges by breaking the problems into smaller parts, reviewing the requirements, and testing my changes as I went. This helped me become more confident in my ability to troubleshoot and complete programming tasks.

## Final Reflection

Overall, this course helped me build a stronger understanding of C# and how software applications are developed and maintained. I gained experience working with existing code, debugging errors, creating classes, and designing both console and graphical applications. Since my goal is to work in game development, I think these skills will be valuable as I continue learning more about programming. Game development involves working with objects, user interfaces, and large amounts of code, so the experience I gained in this course should provide a useful foundation for future projects.
